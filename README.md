# 数砖 · 考研数学真题分析与破题诀平台

面向考研数学（数学一 / 数学二 / 数学三）的真题分析与研习系统。平台整合了 1987–2026 近 40 年共 2185 道考研真题，并以解题招法（破题诀 199 招）与考纲章节双正交轴构建闭环研习体系。

---

## 平台特性

1. **题库底座**
   - 包含 1987–2026 年（40年）全部 2185 道历年考研真题；
   - 覆盖数学一、数学二、数学三全部卷别；
   - 逐题标注考点、题型、解题招法与难度分级。

2. **双轴线体系**
   - **考纲章节轴**：真题大盘、命题结构、考点透视、学习路径、章节练习、按年整卷做题、难题集、跨卷加练；
   - **解题招法轴**：破题诀 199 招（高等数学 11 域、线性代数 6 域、概率统计 7 域）、招法网络拓扑图（756 条转招路径）、阶梯练。

3. **研习闭环与本地持久化**
   - **错题本**：做错题目自动收录，支持连对出本设置与错因归类；
   - **今日复习**：基于 FSRS 间隔记忆曲线智能排期；
   - **收藏夹与笔记墙**：支持重点题打星、自定义标签及每题专属公式/图文笔记；
   - **答题与判分**：已核验答案的客观题支持评分；缺少核验答案时明确提示待核验，不生成标准答案。

4. **辅助工具**
   - **看图学数学**：96 张几何概念可视化直观图卡；
   - **看得见的线性代数**：31 节交互式空间变换课件；
   - **公式手册**：521 条考研数学公式/定理速查与打印卡视图；
   - **组卷模考**：150 分限时真题模拟实战；
   - **反馈广场**：功能交流与互动社区。

5. **免登录即用**
   - 系统内置本地用户身份机制，无需扫码即可直接访问并使用全部功能；
   - 本地运行采用文件持久化；Cloudflare 部署采用按浏览器隔离的云端存储。

> 当前包含预编译前端和数学真题数据。完整答案库、图片识别、英语/政治后端等能力尚缺失；本版复习采用简化间隔排期。具体通过验证的范围与限制见 [功能验证记录](docs/VERIFICATION.md)。

## 启动与使用指南

### 环境要求
- [Node.js](https://nodejs.org/)（使用 Node.js 22 或更新版本；Cloudflare 官方部署工具需要现代 Node 环境）

### 快速启动
在项目根目录下执行：

```bash
npm ci
# 启动本地服务
npm start
```

服务启动后，在浏览器中打开：
```
http://localhost:3000
```
即可进入数砖平台开始研习。

## Cloudflare Workers 部署

```sh
npm test
npm run build
npm run deploy
```

使用 `wrangler.jsonc`，Worker 名称为 `kaoyan-math-2-0`。首次部署创建 SQLite Durable Object `UserStore`；每位访客拥有独立数据。无需预建 D1/KV，也不需要上传 `data/`。

`npm run dev:cloudflare` 启动 Cloudflare 本地预览，`npm run cf:types` 生成绑定类型。

`docs/workflows/` 中提供 Verify 与 Deploy to Cloudflare 工作流模板。当前 GitHub 登录令牌没有工作流写入权限，因此模板尚未启用。后续可将其放入 `.github/workflows/`，并为手动部署工作流配置仓库 Secrets `CLOUDFLARE_API_TOKEN` 与 `CLOUDFLARE_ACCOUNT_ID`。也可以直接从 Cloudflare 控制台关联仓库并使用 `npm run deploy` 部署。

用户个人记录、现有 AI 密钥和本地运行目录均被 `.gitignore` 排除。云端默认使用内置导师提示，可在网站的 AI 设置中按浏览器配置个人模型密钥。
