# 数学、政治与成长打卡整合

## 页面与公共能力

| 入口 | 用途 |
| --- | --- |
| `/` | 跨学科学习总览、每日目标、积分和最近学习 |
| `/math` | 原数学研习平台 |
| `/politics` | 政治题册、章节练习、错题、收藏、复习与模考 |
| `/growth` | 打卡、目标、行动契约、虚拟账本与成长项目 |
| `/library` | 跨学科笔记、收藏、错题与待复习档案 |

公共导航、绿色主色、卡片、浅色/深色主题和阅读字号由 `public/shared/` 统一提供。昵称与 AI 配置由同一访客存储读取。数学答疑、政治答疑与成长复盘共用 AI 设置，接口不回显模型密钥。

## 学习奖励与目标

| 成功行为 | 奖励 | 去重范围 |
| --- | --- | --- |
| 完成一道练习题 | +2 积分 | 当天、学科、题目 |
| 完成一次到期复习 | +3 积分 | 当天、学科、题目 |
| 保存有效笔记（去掉首尾空白后至少 10 字） | +2 积分 | 当天、学科、题目 |
| 完整作答并交卷 | +20 积分 | 当天、学科、试卷 |

日期按北京时间划分。练习奖励不要求答对；正确性、首答正确率和错题状态另行记录。未到期复习不能领取奖励。模考空白/部分交卷不领取完成奖励，完整模考仅领取 20 分，不同时领取逐题奖励。

数学错题自动进入复习队列。复习单独提交评分并重新排期，只产生复习积分与复习目标进度；已有未来排期不会因反复提交同一道错题重置。数学复习仅使用明确核验的选择题答案自动判分，其余题目需自行核对后自评。

默认每日目标为数学 10 题、政治 20 题、复习 5 次、笔记 1 篇，可调整为 1–500。调整目标和开始下一轮打卡均不会重置今日积累。学习事件推动对应学科与行为的行动契约，并推进考研成长里程碑；自动联动的进度不能手动改写。

## 成长系统

保留个人积分、六类代币、手动收支、预支/还款、积分存单、行动契约、虚拟奖励兑换、额外任务和项目里程碑。新增同类兑换前会检查未完成契约。未完成任务达到 15 项时不能兑换追剧奖励。代币新收入优先偿还同币种预支。

积分存单到期返回本金和利息；提前支取只返回本金，不能重复兑付。额外任务当天按不同任务计数，第 6 项起每个新任务可领取一次 5 分奖励。个人项目里程碑奖励只在首次完成时发放，取消再勾选不重复发放。

这些功能是个人虚拟奖励账本，不会进行实际支付。原 AI 文本自动记账改为学习复盘建议：积分由成功学习事件或明确的手动结算写入，避免把模型声称的完成情况当作实际成果。原随机任务奖励统一为固定 5 分，页面与说明保持一致。

## 数据结构与迁移边界

政治 React 源码在 `apps/politics`。原来源文件夹保持原样；题库构建脚本把每一章生成独立公开资源，前端按需读取。所有政治题目使用 `pol:题册:章节:题号` 标识，解决原跨册编号重复问题。

成长后端从原 Python 单机接口整合为 Node 服务，共用现有 Express/Cloudflare Worker。原程序中的个人状态和模型密钥未上传；新访客从空账本开始。既有云端数学记录仍保存在同一 Durable Object 中，本次没有清空记录，也不为历史操作追补积分。

Cloudflare 每位浏览器访客有独立 SQLite Durable Object。大型个人记录以不可变分片保存，避免单行数据大小限制。公共题库缓存不包含用户笔记、答案或 AI 配置。清除身份 Cookie 后会获得新身份；目前未实现登录与跨设备同步。

本地 Node 模式仍以文件保存，适合个人使用；Cloudflare 模式才提供按浏览器隔离。测试使用临时本地目录或新访客 Cookie，不读取个人 `data/`。

## 构建与部署

```sh
npm ci
npm test
npm run build
```

`npm test` 先编译政治界面并生成题库，适用于全新检出。`npm run build` 再进行 Workers 部署预检。Cloudflare Workers Builds 已连接 GitHub 的 `main`，使用 `npm test && npm run build` 构建，再以 `npm run deploy` 发布。生成的政治资源、个人数据、依赖和本地测试产物不提交 Git。

## 内容边界

政治源资料包含生成模板与整理题目，参考答案和年份未独立核验。年份卷在界面命名为「选择题练习卷（导入）」，去掉原伪造的全站均分。数学未知标准答案的题目不会自动判分，主观题 AI 真正评分、图片识别和英语模块未实现。各模块倒计时只是备考估算，不代表官方考试安排。


## 英语与图片更新

英语接入相同积分、可调整每日目标、学科契约、里程碑和公共学习档案。草稿和备份导入不会发放积分。统一 AI 支持私有图片附件、预览和移除；数学、政治、英语及成长共用接口。细节与验证见 [图片与英语说明](AI-IMAGES-ENGLISH.md)。
