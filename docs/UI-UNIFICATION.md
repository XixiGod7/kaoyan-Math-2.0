# 全站界面与学习工具整合

全站使用自适应满宽布局，桌面两侧各保留 20px，手机各保留 14px，并统一卡片圆角与绿色主色。不限制大屏内容最大宽度，导航和工具栏按空间调整；英语试卷矩阵保留内部横向滚动。

## 公共工具

- 顶部 A− / A+ 调节全站字号，范围 90%–140%；点击百分比恢复 100%。字号在数学、政治、英语、成长和档案页面间保留。
- “学习进度”汇总三科学习状态，导出作答、错题、收藏、笔记、复习、模考、英语草稿、成长记录和阅读偏好。导出前等待英语待保存进度完成同步。
- 导出为 `yanzhuan-study.json`，格式 `yanzhuan-study`、版本 1；不包含 AI 密钥或图片附件。当前提供全站导出；“导入旧英语备份”兼容原英语项目格式，不是全站文件的恢复入口。
- 主题、AI 设置、阅读字号和进度导出共用全站入口，英语页面不再重复显示同类控制。

全屏模态弹窗共用 8px 毛玻璃模糊和半透明遮罩，遮罩覆盖顶部导航。英语题目笔记与 AI 助手使用非模态侧栏，无背景遮罩或模糊，正文仍可点击；宽屏时为侧栏预留正文空间。学习进度面板提供带边框的“× 关闭”按钮。页面底部说明和政治导入提示条已移除，政治年份练习卷名称不再显示“导入”。

数学、政治、英语的学科导航共用 64px 桌面高度、学科标题、字号、间距、绿色选中状态与下拉菜单样式。窄屏导航按空间换行。英语页面不再带独立圆角外框，正文与其他学科共用两侧留白。

## 英语学习

- 17 年试卷对应 153 张原始 PNG 缩略图，构建时发布到 `/english-thumbs/`，保持原试卷内容与题目跳转。
- 题目笔记和 AI 助手合并进英语学科导航，导航在打开试卷后保持显示，按需打开侧栏；作答、复习、笔记和模考继续计入公共学习档案及成长积分。
- 笔记跟随当前年份、题号、阅读篇目、翻译题及作文类型；点击题卡、作答区域或“记笔记”更新目标。切换目标时按题读取笔记，未保存草稿保留在当前页面。
- 从学习档案打开英语笔记时，通过年份与题号定位题型、滚动到题目并打开笔记。
- AI 助手上传的图片继续供英语答疑、翻译与作文批阅共用。

本地 Cloudflare 环境的 44 项检查通过，覆盖资源发布、跨访客隔离、学习联动和全站导出。浏览器验证包含 153 张缩略图加载、题目切换与笔记恢复、实际进度文件下载、字号跨学科保留，以及 1920px 宽屏与 390px 窄屏布局。
