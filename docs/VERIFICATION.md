## 修复的主要问题

- 新增 Cloudflare Workers 入口和 SQLite Durable Object 存储；云端免登录访客采用随机 Cookie 身份，个人记录和 AI 配置按浏览器隔离。
- 补齐原先缺失的答题保存接口、收藏分组/星级、组卷和模考历史持久化。
- 移除按题号猜选择题答案、填空题默认答案为 1 的逻辑；忽略原有未核验的解析缓存。当前内置核验答案仅覆盖题目 90101。
- 模考提交不再固定返回 40 分。只统计可核验客观题，未知答案进入 `ungradedIds`，不得将该部分得分当作整卷成绩。
- 未实现的 API 返回 JSON 错误；图片上传返回明确的未支持结果，不再返回虚假的图片编号。
- 修复 8 个不存在的样式文件引用：动态加载改用现有全局样式。原组件独立样式的源码未包含在项目中，不能宣称已恢复这些原始样式。
- 修正保存 AI 设置时未填新密钥会清空旧密钥的问题。
- 移除伪造的全站作答统计和考试预测分数。

## 尚未具备或未验证的能力

- 完整、可靠的标准答案/逐题解析库尚缺失。2185 道题可供浏览，但自动判分仅覆盖内置核验题和后续明确标记 `verified: true` 的解析。
- 主观题的真实 AI 评分、图片上传/识别/看图答疑和讲解图生成尚未实现。
- 复习算法是简化的间隔重复排期，不能描述成完整 FSRS 模型。
- 英语、政治、巩固练习册等前端入口保留在已有构建文件里，项目未包含相应完整后端/题库，不属于本次通过验收的功能。
- 社区共享评论、积分、邀请等接口未实现。当前反馈记录在云端按访客隔离，并非多人共享社区。
- 外部大模型真实调用未作为自动测试的一部分。线上默认为内置启发式提示；如需真实大模型，须在该浏览器的 AI 设置中自行填写密钥。内置提示也不能充当经过核验的数学解答。
- 项目包含预编译前端文件，没有 React/Vite 原始源码。后续完整 UI 迭代应补齐源码；本次对已有构建文件做了有限兼容修复。
- 云端身份不会跨设备同步；清除 Cookie 后得到新身份，原记录不会显示。本地 Node 服务仍是适合个人使用的文件存储模式。

## 部署结构

静态资源由 Workers Assets 提供；`/api/*` 经 Worker 转交该访客的 Durable Object，再通过 Cloudflare 的 Node HTTP 适配器运行既有 Express 应用。SQLite 同步写入取代云端文件写入；用户数据不依赖 Worker 内存或临时文件。

实现参考：[Cloudflare Express 部署指南](https://developers.cloudflare.com/workers/tutorials/deploy-an-express-app/)、[Node HTTP 适配器](https://developers.cloudflare.com/workers/runtime-apis/nodejs/http/)、[Durable Objects SQLite 存储](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)。
