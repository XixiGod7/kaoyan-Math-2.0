## 兼容与使用变化

- 本地运行需要 Node ≥22.13；`data/study.sqlite` 是主要事务存储。复制运行中的数据库时应包含 WAL，或先正常关闭服务。原 JSON 不删除。
- 全站“学习进度”支持恢复新备份及旧英语备份；清理前先导出，确认后只清理选中的类别。恢复及账号迁移都会保留或报告冲突，不会把旧本地队列直接投递到另一账号。
- AI 地址仅支持设置面板的官方供应商。现有非官方网关需要更换，暂不支持任意域名。
- 未自动删除闲置访客，未恢复完整数学源码，未建立全部性能指标；以上限制在逐项表中保留，避免把代码优化等同于已量化的性能收益。
