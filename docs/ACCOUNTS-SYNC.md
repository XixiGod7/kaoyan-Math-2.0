# 账号、双重保存与浏览位置

顶部“登录 / 注册”支持用户名、密码和恢复码。密码为 12–128 个字符；用户名会统一全角、半角和大小写。注册、修改密码和找回密码后会显示新的恢复码，仅显示一次，可复制或下载。旧恢复码随密码更新失效，其他设备的旧会话也会撤销。

登录后数学、政治、英语与成长数据使用同一账号的云端存储。现有访客记录自动合并：收藏和记录去重，同题笔记保留双方文字，同日相同学习事件不重复领取积分。旧访客副本保留，避免迁移失败丢失资料。现有 AI 设置和图片通过服务器内部通道迁移，不经过学习备份接口。

学习记录同时保存到浏览器 IndexedDB 与 Cloudflare SQLite Durable Object。正常联网时保存操作进入本地队列后提交云端；连接失败时显示本地保存提示，恢复连接、窗口重新获得网络或定时同步后补交。自动判分和奖励以服务器处理结果为准，离线不伪造判分或奖励。顶部“保存与同步”显示待处理数量，可立即同步、选择笔记冲突版本、导出本地学习备份。

同一账号的两台设备修改同一笔记或同一英语草稿时，会保留待同步内容并提示选择版本。英语模考计时变化自动合并；不同题目的作答合并，同一道题的不同选择需要处理冲突。未经处理的队列不会静默丢弃。账号过期后可重新登录以恢复队列；账号切换时队列按账号隔离，旧标签页不能向新账号写入旧数据。

各科全站入口自动回到上次位置；“科目首页”可回到首页。显式题目链接优先。记录包含 URL、滚动位置、数学练习题号与筛选、政治章节题目和复习/收藏页码、英语篇目/年份/试卷分区、语法和词组分页、成长页面以及学习档案分类。浏览位置先存本机，再保存云端。英语笔记和 AI 面板始终覆盖正文，背景保持清晰。

## 安全与存储边界

- 密码使用带随机盐的 scrypt（N=32768、r=8、p=3）；恢复码和会话令牌仅保存 SHA-256 摘要。会话 Cookie 为 HttpOnly、SameSite=Lax，线上使用 Secure 和 __Host- 前缀，30 天到期。
- 注册、登录与密码恢复限制尝试次数，并限制密码计算并发和请求大小。浏览器接口拒绝跨站修改，已移除旧占位登录码。
- 同步操作使用编号去重并核对内容，防止网络重试重复记账。每个用户的写操作串行执行，减少并发覆盖。
- 切换 AI 接口域名或测试另一个域名时，必须显式提供对应密钥，避免已保存的密钥被发往新地址。
- 线上访客不会自动继承服务器环境变量中的共享 AI 密钥；应在自己的账号内配置个人密钥。已有访客和账号内的配置保留。
- 本地文件使用临时文件和原子替换；旧本地数据迁入第一个实际访客的独立目录，原文件仍保留。默认本地服务仅监听本机地址。
- 学习备份不包含密码、恢复码、会话令牌、AI 密钥或图片文件。图片和模型设置仍在对应账号的云端独立保存。浏览器清理网站数据会删除本机副本；账号的云端记录可通过登录恢复。
- 无邮箱找回渠道，遗失密码及恢复码后无法自动找回账号，因此应下载恢复码。

Cloudflare 配置保留 v1 UserStore 迁移，新增 v2 AuthStore。现有访客 Cookie 仍访问原有存储，注册登录时迁入账号存储；不需要重新创建网站或清空现有数据。

## 验证与效率

新增 6 组账号与同步测试，覆盖访客合并、跨设备读取、密钥排除、恢复码轮换、旧会话撤销、重试去重、笔记冲突、跨站拒绝、过期和切换账号的隔离、登录限流。与原有功能测试合计 50 项；本地 48 项通过，2 项仅在 Cloudflare 地址上执行。Cloudflare 本地运行环境也验证了账号完整流程。界面实测了英语覆盖面板、注册页面、断网笔记与恢复连接后的保存、科目导航恢复。

英语重型页面改为按需加载，主脚本从约 620 KB 降为约 402 KB。模考草稿仍先保存本机，云端计时保存合并为约 10 秒一次；公共题库同时请求复用加载任务，总览重复请求合并，模型返回长度有上限。当前全部依赖审计报告没有已知漏洞；测试与审计不代表消除所有可能的安全问题。
