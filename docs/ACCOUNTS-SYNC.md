# 账号、双重保存与浏览位置

顶部“登录 / 注册”支持用户名、密码和恢复码。密码为 12–128 个字符；用户名会统一全角、半角和大小写。注册、修改密码和找回密码后会显示新的恢复码，仅显示一次，可复制或下载。旧恢复码随密码更新失效，其他设备的旧会话也会撤销。

登录后数学、政治、英语与成长数据使用同一账号的云端存储。现有访客记录自动合并：收藏和记录去重，同题笔记保留双方文字，同日相同学习事件不重复领取积分，长期累计保留窗口外总计。迁移冻结来源并记录目标导入标记，旧访客副本保留；部分附件迁移失败会提示，再次登录可重试，不覆盖同期账号新记录。AI 设置和图片通过服务器内部通道迁移，不经过学习备份接口。部分时间、尝试数和复习阶段仍以现有账号值优先。

学习记录同时保存到浏览器 IndexedDB 与 Cloudflare SQLite Durable Object；本地服务器使用 SQLite WAL。正常联网时保存操作进入本地队列后提交云端；连接失败时显示本地保存提示，恢复连接、窗口重新获得网络或脏状态定时同步后补交。自动判分和奖励以服务器处理结果为准，离线不伪造判分或奖励。顶部“保存与同步”显示待处理数量，可立即同步、选择笔记冲突版本、导出本地学习备份。永久错误单独隔离，不阻塞其他独立记录；同一记录仍保持顺序。

同一账号的两台设备修改同一笔记或同一英语草稿时，会保留待同步内容并提示选择版本。同一模考尝试的计时变化取较大值，不同题目的作答合并，同一道题的不同选择或不同尝试需要处理冲突。未经处理的队列不会静默丢弃。账号过期后可重新登录以恢复队列；账号切换时队列按账号隔离，旧标签页不能向新账号写入旧数据。

“学习进度 → 恢复学习备份”支持新版全站备份、旧英语备份及本地学习备份，先预览内容，再选择合并或替换。恢复包含标签、星级、草稿、位置及字体/主题偏好；本地待同步操作不跨账号自动重放。管理存储须先导出，并确认清理选中的类别。

各科全站入口自动回到上次位置；“科目首页”可回到首页。显式题目链接优先。记录包含 URL、滚动位置、数学练习题号与筛选、政治章节题目和复习/收藏页码、英语篇目/年份/试卷分区、语法和词组分页、成长页面以及学习档案分类。浏览位置先存本机，再保存云端。英语笔记和 AI 面板始终覆盖正文，背景保持清晰。

## 安全与存储边界

- 密码使用带随机盐的 scrypt（N=32768、r=8、p=3）；恢复码和会话令牌仅保存 SHA-256 摘要。会话 Cookie 为 HttpOnly、SameSite=Lax，线上使用 Secure 和 __Host- 前缀，30 天到期。
- 注册、登录与密码恢复限制尝试次数，并限制密码计算并发和请求大小。浏览器接口拒绝跨站修改，已移除旧占位登录码。
- 同步操作使用编号去重并核对方法、路径和正文，不一致返回 409。业务、奖励、修订及重放记录在同一存储事务中提交。普通写操作串行；模型网络等待移出写锁，最终持久化使用短事务及最新会话合并。
- AI 仅允许顶部预设中的官方 HTTPS 主机，拒绝重定向及自建网关；切换主机时必须显式提供对应密钥。请求和响应均有大小及超时限制，支持取消。
- 线上访客不会自动继承服务器环境变量中的共享 AI 密钥；应在自己的账号内配置个人密钥。已有访客和账号内的配置保留。
- 本地 Node 最低版本为 22.13，主要事务文件为 `data/study.sqlite`，认证有索引。旧身份目录 JSON 惰性导入，原文件保留；旧根目录数据不再由首个访客领取。本机所有者使用 `node scripts/export-legacy.cjs <新的绝对路径.json>` 导出，再从登录后的恢复入口导入。默认仅监听回环地址，并在身份处理前校验可信 Host。
- 学习文档累计上限 24 MB、单类 8 MB；图片独立限制 100 张/50 MB、每张 5 MB。试卷及草稿另有条目限制。已有超额资料允许导出与缩减。匿名身份创建和写入有按 IP 预算，超限返回 429；闲置访客尚未自动删除。
- 学习备份不包含密码、恢复码、会话令牌、AI 密钥或图片文件。图片和模型设置仍在对应账号的云端独立保存。浏览器清理网站数据会删除本机副本；账号的云端记录可通过登录恢复。
- 无邮箱找回渠道，遗失密码及恢复码后无法自动找回账号，因此应下载恢复码。

Cloudflare 配置保留 v1 UserStore 迁移，新增 v2 AuthStore。现有访客 Cookie 仍访问原有存储，注册登录时迁入账号存储；不需要重新创建网站或清空现有数据。

## 验证与效率

当前 `npm run verify` 87 项，本地 85 通过、2 项 Worker 专用跳过；全新隔离 Wrangler 环境的账号/API/学习联动/恢复契约共 45 项全部通过。另有真实浏览器离线笔记、重连同步、备份预览/恢复/导出、计时刷新及虚拟词表验证。结果和未完成的压力、屏幕阅读器、弱网及故障测试见 [审查改进实施记录](PROJECT-REVIEW-FIXES-2026-10-05.md)。

英语/政治重型页面及弹窗按需加载，英语词频列表虚拟化，计时显示独立更新；答案立即保存，计时约 10 秒一次及离开时保存。同步只传变化文档/英语键，IndexedDB 仅写变化的类别记录。仍有大 JSON、序列化与本地同步 SQLite 成本，未量化长期历史下的 p95；依赖审计没有已知漏洞也不代表消除全部业务风险。
