# 图片与英语整合验证

本轮整合为数学、政治、英语与成长复盘提供共用的图片存储和模型调用。图片可预览、移除、与文字一起发送；数学答疑会保留会话图片供后续追问。数学手写答案图片提供 AI 自评反馈，不代替已核验的标准答案。

根据用户打开的 [商汤 Token Plan 官方文档](https://platform.sensenova.cn/docs)，使用 `https://token.sensenova.cn/v1/chat/completions`，将图片以 `image_url` 内容块和完整 `data:image/...;base64,...` 发送。商汤图片请求默认使用 `sensenova-6.8-flash-lite`；文字保留所设置的模型。统一设置可单独指定图片模型。只展示正式答复，接口出错或未配置密钥时明确说明，不能声称已识别图片。

图片按访客身份隔离，限制为 PNG/JPEG/WebP、单张不超过 5 MB、单次最多 3 张，保存空间最多 100 张或 50 MB。服务端检查文件签名和 MIME 类型，拒绝 SVG 等不支持文件；私有图片返回 `no-store` 与 `nosniff`。图片和密钥均不提交到 GitHub。

英语源码基准为 `XixiGod7/kaoyan-english@f1120a0`。整合公开学习资料及完整 React 功能；统一题目标识、参考答案和持久化方式，避免精读与试卷重复计数。2011 年源资料缺一题，界面说明按已载入题目判断完成度。英语个人记录按 Cookie 保存；旧应用的个人数据、密钥和本地服务代理未复制。

自动检查共 44 项。覆盖旧模块回归、PNG 上传与删除、1 MB 以上图片分片保存、图片及英语记录隔离、商汤多模态请求格式与模型选择、SSE 中文拆包、正式答案与思考字段分离、缺少正文与错误响应、英语草稿、英语与成长奖励、跨年份/跨功能题目标识去重、整卷/部分交卷、缺题资料、到期词汇复习、同义替换、笔记和每日目标。

无密钥时的功能与模型请求格式已自动验证；外部模型真实识别及评分质量取决于用户配置的接口、模型和额度。资料参考答案不冒充额外核验的官方答案。
