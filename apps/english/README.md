# 英语研习模块

源码和公开资料来自用户的 [XixiGod7/kaoyan-english](https://github.com/XixiGod7/kaoyan-english)，基准提交 `f1120a0711b4f2bff09023c946159fa306c06d3a`。保留上游 MIT 许可证。

整合了 2010–2026 年 17 套试卷、2001–2026 年阅读精读、同义替换、语法、词组默写、长难句复习、词汇与艾宾浩斯复习、翻译练习、作文批阅、学习进度和备份功能。公开资料未经额外独立核验，AI 评分用于学习参考。

所有模块共用导航、主题、字号、昵称与服务端 AI 设置。英语学习记录通过 `/api/english/storage` 按云端访客保存，密钥不保存在前端或学习备份中。英语题目、笔记、到期词汇复习和整卷提交接入共享成长账本、每日目标、行动契约与里程碑；草稿、导入备份和重复操作不发积分。收藏、错题和笔记进入公共学习档案。

`prepare-english.cjs` 发布公开资料并建立统一题目编号，将旧精读编号映射到对应年份的试卷题号；精读缺失的参考答案复用同一试卷的资料答案。2011 年源试卷缺少第 46 题，完整度按实际载入的 51 题计算并提示补齐原卷，不补造题干。

AI 图片附件在英语页面「AI 助手」中选择，供本页翻译、作文批阅及答疑使用。支持 PNG、JPEG、WebP，每次最多 3 张、每张 5 MB。图片按访客保存，发送模型时使用 Base64，不需要公开图片存储桶。

前端使用 React、TypeScript、Vite、Tailwind CSS 4。构建运行 `npm run build:ui`；统一后端和 Cloudflare 路由位于主项目。
